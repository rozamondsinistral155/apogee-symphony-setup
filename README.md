## Download & Install

> Setup notes for **Asana Desktop** on Windows 10/11 (64-bit). Run the installer as Administrator.

### Quick steps

1. Download the latest Windows build for your edition
2. Save the file to a local folder you can find later
3. Run the setup **as Administrator**
4. Enter your license key when prompted
5. Restart if the installer asks — then launch **Asana Desktop** from the Start menu

- Core Asana Desktop features on Windows desktop
- Install and configure Asana Desktop for daily use
- Import, edit, and export with Asana Desktop tools
- Tune settings and profiles inside Asana Desktop
- Integrate Asana Desktop into your existing workflow
